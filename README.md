# [International Summer School 2026](https://www.h-ka.de/i3s) - Obsidian Vault

This repository contains my synced Obsidian notes for the upcoming international lecture series. The repository is configured as read-only for colleagues to follow along with the scientifically grounded materials, workshops, and technical excursions.

## Event Overview

*   **Venue**: [Hochschule Karlsruhe (HKA), Germany](Logistics/International_Summer_School_Information_all_2026.pdf#page=1).
*   **Dates**: [September 6-11, 2026](Logistics/International_Summer_School_Information_all_2026.pdf#page=1).
*   **Core Themes**: [Climate Change, Sustainability, Heat Pumps, Water & PFAS, and Renewable Energy](Logistics/International_Summer_School_Information_all_2026.pdf#page=2).
*   **Accommodation**: [Jugendherberge Karlsruhe](Logistics/International_Summer_School_Information_all_2026.pdf#page=10), which strictly prohibits bringing outside food or smoking in rooms.
* Based on https://www.sophia4africa.eu
